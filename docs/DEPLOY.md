# Deploying

Two things ship, and only one of them is a service.

## The proxy is not deployed

`interlock-mcp` speaks MCP over stdio. It runs wherever the agent runs — a
laptop, a container beside the agent, a CI job — and is installed, not hosted:

```
npx interlock-mcp --mandate ./mandate.yaml
```

Hosting it would mean putting a rail credential and a ledger on a machine the
agent talks to over a network, which buys nothing and adds an attack surface to
the one component whose entire purpose is to be the thing between the agent and
the money.

## The console — Render

`render.yaml` is a blueprint. Point Render at the repository and it reads it.

The part that matters is the disk. The ledger **is** the exactly-once
guarantee: it is what makes a second identical refund a no-op rather than a
second refund. A container filesystem that resets on deploy would discard it,
and every restart would look like a fresh install with no memory of what it had
already paid. `PRAGMA synchronous = FULL` fsyncs to that volume on every state
change, so it has to be a real disk.

That rules out Render's free plan, which has no persistent disk. The blueprint
asks for `starter` for that reason and not for performance.

`INTERLOCK_CONSOLE_TOKEN` is generated by Render and never committed. Read it
from the dashboard once; it is the only credential the console has.

**The deployment holds no rail credential.** `RAZORPAY_KEY_ID` and
`RAZORPAY_KEY_SECRET` are deliberately absent from the blueprint: the console
reads a ledger and resolves what a human decides, and none of its routes can
reach the rail. A compromise of the public surface cannot move money.

### Health

`/health` returns 503 while boot recovery is still settling intents that were
in flight when a previous process died, and Render holds traffic off until it
goes green. That is the intended behaviour, not a failure to start — a process
deciding against a ledger it has not finished reconciling would be deciding
against incomplete information.

## The landing page — GitHub Pages

Settings → Pages → Source `main`, folder `/docs`. That serves
`docs/index.html`, which is generated; see [design/README.md](design/README.md)
for how to rebuild it.

Vercel works too: point it at the repository, no build command, output
directory `docs`.

## What a deployment does not prove

Everything here runs against the mock rail. Deploying the console does not make
the live Razorpay adapter tested — that needs `scripts/rail-probe.mjs` and a
test-mode key, and what it finds goes in `rail-notes.md`.
